# NASA Mission Control Dashboard

A static NASA-themed mission control dashboard with:

- NASA Eyes embed
- Planetary Positions view
- Telugu Calendar / panchangam view

## GitHub Pages

This project is plain HTML, CSS, and JavaScript. It can be hosted directly from the repository root with GitHub Pages.

1. Push this folder to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings > Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Select branch **main** and folder **/**.
6. Save.

Your site will publish at:

```text
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
```
